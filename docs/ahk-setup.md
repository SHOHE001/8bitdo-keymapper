# AutoHotkey でキー割当を Windows に適用する

8BitDo Keymapper で作ったプロファイルを、**実機ファームに書き込まず**、Windows の OS レベルのリマップとして適用する手順。
**PC を再起動しても自動で適用される**ようにスタートアップに登録する。

> このアプリは AutoHotkey v2 用の `.ahk` を書き出すだけで、適用そのものは AutoHotkey が行う。
> リマップは特定デバイスに限定せず**全キーボード共通**で効く（純 AutoHotkey のため）。

## 前提

- 対象 OS: **Windows**
- エンジン: **AutoHotkey v2**（v1 では動かない）

## 手順

### 1. AutoHotkey v2 をインストール

<https://www.autohotkey.com/> から v2 をインストールする。インストール後、`.ahk` ファイルが AutoHotkey64 に関連付けられる（ダブルクリックで実行できる）ことを確認する。

### 2. アプリから `.ahk` を書き出す

1. 8BitDo Keymapper でプロファイルを選択する。
2. 左サイドバーの **「AHK 書き出し」** ボタンを押す。
3. 保存先を聞かれるので、**固定パス**に保存する（例: `%USERPROFILE%\8bitdo-keymap\profile.ahk`）。
   - 自動起動のショートカットがこのパスを指すので、以後も同じパスに上書き保存すると差し替えが楽。
4. 変換できない割り当てがあった場合はトーストで「N 件スキップ」と表示される（下記「制約」参照）。

### 3. 動作確認

保存した `.ahk` をダブルクリックする。タスクトレイに AutoHotkey の緑アイコンが出れば常駐成功。メモ帳などでリマップしたキーを押して、意図どおり送出されるか確認する。

### 4. 再起動後も自動適用されるよう登録する

1. `Win + R` を押して `shell:startup` と入力 → Enter（スタートアップフォルダが開く）。
2. 手順 2 で保存した `.ahk` への**ショートカット**をこのフォルダに作る。
   - `.ahk` を右クリック →「その他のオプションを表示」→「送る」→「デスクトップ（ショートカットを作成）」などでショートカットを作り、スタートアップフォルダへ移動する。
3. 一度サインアウト → サインイン、続けてフル再起動して、ログオン時に自動でリマップが効くことを確認する。

### 5. プロファイルを更新したとき

1. アプリで編集し、手順 2 と**同じパス**に上書き書き出しする。
2. タスクトレイの AutoHotkey アイコンを右クリック →「Reload Script」、または再ログオンで反映する。

## 変換の対応表

| 割り当て | AutoHotkey v2 への変換 |
|---|---|
| 単キー（key） | native remap（`a::z` のような直接リマップ） |
| コンボ（combo） | `Send "^+s"`（Ctrl=`^` / Shift=`+` / Alt=`!` / Win=`#`） |
| マクロ（macro） | 複数行ブロック。`delayMs` はそのステップ送出**前**の `Sleep` |
| メディア（media） | `Send "{Media_Play_Pause}"` ほか |
| マウス（mouse） | `Click` / `Click "Right"` / `Click "Middle"` / `Send "{WheelUp}"` など |
| 無効化（disabled） | `return`（キーを無効化） |

## 制約・注意

- **Super A / Super B**: 8BitDo 独自の物理ボタンで、Windows にどのキーコードで届くか不明のため変換対象外（スキップされ警告が出る）。実機で押したときに送られるコードが分かれば、別途リマップを追記できる。
- **日本語 IME**: IME がオンのとき、英字の送出が変換対象になることがある。基本は IME オフでの利用を想定。
- **記号キー**: US 配列前提で変換している。JIS 配列だと一部記号がずれる可能性がある。
- **適用範囲**: 特定デバイス限定ではなく全キーボードに効く。8BitDo 以外のキーボードでも同じリマップがかかる。
- 8BitDo 実機ファーム/本体メモリへの書き込みは一切行わない（文鎮リスクなし）。
